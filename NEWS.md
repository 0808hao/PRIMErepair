# PRIMErepair 0.1.0

First research source release. Freezes the numerical kernels of Step133
v0.4.1 (including Step131 deterministic acquisition) and adds a validated public
API, named-ID alignment, duplicate-label protection, RNG restoration, separate
methodology/results export, documentation and regression tests.

No model fitting, feature extraction, candidate tuning or clinical-margin
selection is performed by this package. No performance guarantee beyond the
documented certificate scope is implied by a software release.
