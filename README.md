# PRIMErepair 0.1.0

Budgeted certification of the minimum input cost among locked prediction
alternatives satisfying groupwise binary Brier-loss constraints.

Place the downloaded `PRIMErepair.tar.gz` archive in your current working
directory (shown by `getwd()`), then run:

```r
install.packages("PRIMErepair.tar.gz", repos = NULL, type = "source")
library(PRIMErepair)
ex <- prime_example()
fit <- prime_audit(ex$pool, prime_oracle(ex$y), epsilon = 0.002)
print(fit)
prime_truth(ex$pool, ex$y) # retrospective evaluation only

# Separate probability regime: select alpha before looking at queried labels.
cs <- prime_audit(ex$pool, prime_oracle(ex$y),
  method = "decision_cell_residual_wor_EB", alpha = 0.05)

# Separate fixed-budget point estimator: no certificate.
point <- prime_lure(ex$pool, prime_oracle(ex$y), budgets = 0.1)

# Optional: writes a NEW directory, with two separate table folders.
out <- tempfile("PRIMErepair_export_")
prime_export(fit, out)
```

Only R's standard packages are required; no compiler or internet connection is
needed for installation. R >= 4.3.0. See `help(package="PRIMErepair")`,
`prime_methods()`, and the installed `doc/METHODS.md` / `doc/USER_GUIDE.md`.

## Contract

- Lock candidates, predictions, costs, proxy probabilities and group definitions
  before querying audit labels. Train and tune models on separate development data.
- The reference must have maximal input cost. Cost is a declared nonnegative
  scalar; the prior experiments used channel/feature-family counts, not money.
- Positive loss gap means the alternative is worse than the reference.
- Certified minimum cost does not require ranking every candidate of equal cost.
- `reveal(indices)` returns binary labels in request order. Unqueried labels are
  not passed to acquisition. `prime_oracle(y)` is a retrospective convenience.
- Budgets count UNIQUE unit labels. Epochs and people are different label units.
- Finite-pool certification does not establish population noninferiority,
  a clinically validated margin, removal of leakage, or deployment safety.
- Probability guarantees are for each prespecified alpha separately, across
  candidates/groups/times in one fixed-pool audit. They are not simultaneous
  across unrelated audits or post-hoc alpha selection.
- LURE uses prespecified fixed label budgets. Its plugin decisions have no
  confidence certificate. Deterministic proxy-completed means are heuristics.

No patient-level or subject-level research data are bundled. All executable
examples and test fixtures are synthetic. Aggregate Step133 evidence is in
`inst/extdata`; it is not regenerated by installing this package.
